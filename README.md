# Gearbox-Condition-Monitoring
Code used to measure effectiveness of different CM techniques applied to gearbox vibration data.

Datasets

These will need to be downloaded from their respective websites:

CWRU - https://engineering.case.edu/bearingdatacenter
Paderborn - https://mb.uni-paderborn.de/en/kat/research/bearing-datacenter/data-sets-and-download
OpenEI - https://data.openei.org/submissions/738
